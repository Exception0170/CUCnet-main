Система Web-Proxy сети CUCnet

Система прокси позволяет получить доступ к внутренним сайтам сети из внешнего интернета по протоколу HTTPS.
Эндпоинт для доступа: cucnet.ru/w/{имя сайта}.cucnet
Пример: https://cucnet.ru/w/exceptionhome.cucnet/cucnet.html (Мой домашний комп)
Траффик идет по HTTPS к главному серверу(cucnet.ru), а затем перенаправяется внутри сети по HTTP.
web <--HTTPS--> cucnet.ru <--HTTP--> example.cucnet
Если вы не хотите, чтобы к вашему сайту получали доступ по HTTP, просто запретите к нему доступ для всех, кроме шлюза(10.8.0.1)
ℹ По проблемам с прокси, обращайтесь к администратору.
