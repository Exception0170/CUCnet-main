Подключение к сети

Для того, чтобы подключиться к сети, нужно скачать ПО Wireguard: Ссылка
Далее, нужно получить файл .conf - через телеграмм бота (Обращайтесь к @exception17, если бот не работает)
В wireguard-е импортируем наш файл конфигурации - и подключаемся к сети.
MacOS: запустите и выберите "импортировать туннель из файла"
Windows: запустите GUI и импортируйте туннель из файла
Mobile: скачайте приложение из AppStore/Google play и импортируйте файл
Lunix: установите пакет wireguard
Скопируйте конфигурационный файл в /etc/wireguard/[имя].conf
Запустите интерфейс: sudo systemctl start wg-quick@[имя]
Для управления можно использовать утилиту wg, или на некоторых дистрибутивах появится интерфейс в настройках сети.

Проверка подключения

Для проверки достаточно пропинговать центральный сервер: 10.8.0.1
Для проверки DNS проверьте доступность: server.cucnet
